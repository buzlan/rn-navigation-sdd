# RN Navigation SDD Playground

This repository is created to explore Spec-Driven Development using Spec Kit in practice.
The goal is to understand the SDD workflow and apply it to a small but realistic React Native demo project.
The demo project focuses on React Native navigation architecture with multiple navigation patterns.
It will be used to validate how requirements, architecture decisions, and implementation steps can be defined before coding.
The project will include flows such as authentication, tabs, nested stack navigation, drawer navigation, modals, and deep linking.
The working process follows the Spec Kit pipeline:
constitution → specify → plan → tasks → implement.
The main objective is not only to build a demo app, but also to document and learn the full workflow step by step.
