# Project Idea

React Native demo app to explore Spec-Driven Development with multiple navigation patterns.

## Goal
Demonstrate how SDD helps design navigation architecture before implementation.

## Planned navigation patterns
- Auth flow
- Bottom tabs
- Stack inside tab
- Drawer
- Modal
- Deep linking
- Typed route params

## Why this project
This project is small enough for a demo but complex enough to validate navigation requirements and architecture decisions.
